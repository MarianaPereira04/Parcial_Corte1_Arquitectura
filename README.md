# Parcial Corte 1 — Arquitectura de Software

Diagnóstico arquitectónico y aplicación de patrones de diseño sobre el sistema ERP Iglesias.

## Integrantes

- Danay Mariana Pereira Ospina

## Descripción del proyecto

Este repositorio contiene el desarrollo del Parcial 1 de Arquitectura de Software.  
El objetivo es diagnosticar la arquitectura del sistema ERP Iglesias y proponer mejoras mediante la aplicación de patrones de diseño creacionales y estructurales junto con principios SOLID.

## Stack del sistema

- Backend: Java (Spring Boot)
- Frontend: Angular
- Base de datos: PostgreSQL
- Contenedores: Docker
- Orquestación: Docker Compose

## Documentación

- Diagnóstico arquitectónico
- ADR (Architecture Decision Record)
- Diagrama MER
- Pruebas funcionales
